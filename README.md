17. SUSCRIPCION ABSTRACTA

Crea la clase abstracta Suscripcion con el atributo nombreUsuario, un constructor, el método abstracto calcularCuotaMensual() y el método concreto mostrarUsuario(). 

• SuscripcionFija tiene cuotaMensual, y calcularCuotaMensual() la devuelve. 

• SuscripcionPorUso tiene gigasConsumidos y precioPorGiga, y calcularCuotaMensual() devuelve su producto. 

• Los importes y los gigas no pueden ser negativos. 

• En Main, intenta escribir new Suscripcion("x"), anota el error de compilación y borra la línea. 

Clase de prueba: MainSuscripcion, con un array Suscripcion[] y un bucle que muestre el usuario y la cuota de cada una, y al final la suma de todas las cuotas.
